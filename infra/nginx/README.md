# nginx hardening (reference)

LocalWP ignores the site's `conf/` directory (`/.gitignore`), so the live
templates there are regenerated by the Local app and are not versioned.

These two files are the hardened reference copies applied to the local site
on 2026-11-19:

- `server_tokens off` (no version leak in `Server:` header)
- `client_max_body_size 64m` (was 1000M)
- `limit_req_zone` / `limit_req` for PHP (30 r/s, burst 60)
- `fastcgi_hide_header X-Powered-By`
- 30-day immutable cache for versioned CSS/JS/fonts/images

To reapply to a LocalWP site, copy them into `<site>/conf/nginx/` (the
`{{...}}` placeholders are filled by Local when the site starts), then run
`nginx -t` and reload. For a production server, port the same directives
into the distro vhost; also upgrade nginx to 1.30.7+ / 1.31.9+.

Security headers (X-Content-Type-Options, X-Frame-Options, Referrer-Policy,
Permissions-Policy, CSP) are already emitted by the TAP plugin, so they are
deliberately not duplicated here.
